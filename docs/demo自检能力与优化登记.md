## 十四、自检能力与验收自动化（★2026-09-25 逐项实测★）

> 回答一个问题：**我能不能自己看结果、自己发现错误、自己判断要不要优化？**
> 结论：**能。** 下列每一项都是本轮**实际跑通**的，不是推断。

### 14.1 已实测的能力清单

| 能力 | 实测方法与结果 | 用途 |
|---|---|---|
| **截屏看见渲染结果** | `chrome --headless --screenshot=... file:///...` → 读取 PNG，**完整看到**中文、数值、布局、配色 | 每轮改动后自查视觉效果 |
| **DOM 断言（数字校验）** | `--dump-dom` 抓渲染后 DOM：读到 `id="v1">12.06 ms` / `v3">96.8%` | 断言"页面数字 == 权威数字" |
| **断网模拟** | `--host-resolver-rules="MAP * ~NOTFOUND"` → 页面照常渲染 | 自动验证"断网可放" |
| **外部请求审计** | puppeteer 监听 `request`：非 `file:`/`data:` 请求计数 → **外部请求数 = 0** | 硬性守住"零 CDN" |
| **JS 错误捕获** | 注入 `undefinedFunctionXYZ()` → 自动抓到 `Uncaught ReferenceError` | 白屏/脚本错误自动发现 |
| **交互验证** | `puppeteer-core` 驱动本机 Chrome（**复用已装浏览器，不下载 Chromium**）：点击标签 → 面板正确切换 | 验证对比开关、多屏切换、参数滑杆 |
| **ECharts 离线渲染** | 本地化 `echarts.min.js`（1,030,855 B）+ 断网 + `file://` → 柱状图正常出图，**0 外部请求、0 JS 错误** | 图表屏可验证 |
| **原生 WebGL 离线渲染** | `file://` + 断网 + swiftshader：`WebGL 1.0 可用`，180 点云绘制成功，**像素回读 OK** | ★3D 可零依赖实现（见 14.3） |
| **控制台/失败请求监听** | puppeteer 监听 `pageerror` + `requestfailed` | 回归时发现隐性失败 |

### 14.2 自检流水线（可直接复用）

```bash
# 0) 前置（已就绪，无需你操作）
#    Chrome : C:/Program Files/Google/Chrome/Application/chrome.exe
#    puppeteer-core: C:/Users/ASUS/.workbuddy/binaries/node/workspace/node_modules

# 1) 断网截图（我读图自查）
chrome --headless --disable-gpu --hide-scrollbars \
  --host-resolver-rules="MAP * ~NOTFOUND" --window-size=1600,1000 \
  --screenshot="demo/_selfcheck/shot.png" "file:///<abs>/demo/index.html"

# 2) 数字断言 + 外部请求审计 + JS 错误（机器判）
node demo/tools/selfcheck_audit.js

# 3) 多屏遍历截图（逐屏看）
node demo/tools/selfcheck_shots.js
```

**判定三原则**：① 外部请求必须 = 0；② JS 错误必须 = 0；③ 页面数字必须逐字等于《双轨交叉验证对照表》。任一项不过 → 自行修复后重跑。

### 14.3 ★实施期发现的真实约束★：vendor 库获取不稳定

| 库 | 体积 | 实测结果 |
|---|---|---|
| **ECharts 5.5.1** | 1,030,855 B | ✅ 成功（26 s）；**但首次因超时被截断 → 白屏**（`echarts is not defined`），必须校验完整性 |
| **Three.js r147** | 607,784 B | ⚠️ **三次全失败**（连接重置 / 超时，最远只收到 209,750 B） |

**对策（按优先级）**：

1. **核心 demo 走"零依赖"路线**：图表用**手写 SVG/DOM**（柱状 / 折线 / 漏斗 / 时间线）——体积 **0 依赖**、彻底消除"库损坏白屏"，且与 `aidemo`（纯 HTML/CSS/JS、零库）做法一致。
2. **3D 走"原生 WebGL 手写"**：已实测 `file://` 下 WebGL 可用 → 球体 + 经纬网 + 651 星点云（Fibonacci 球面分布）+ 轨道弧 + 仰角掩蔽圈，全部可零库实现。
3. **若确实需要 Three.js 观感**：请在**本机**下载一次（沙箱网络不稳）：
   ```
   curl -L -o demo/vendor/three.min.js https://cdn.jsdelivr.net/npm/three@0.147.0/build/three.min.js
   ```
   下载后告知，我会校验 607,784 B 再使用。
4. 任何库入库前**一律校验字节数/hash**（记入 `demo/vendor/CHECKSUMS.txt`）。

### 14.4 迭代机制（本轮起生效）

1. 每次改动 → 跑 14.2 流水线 → 截图存档到 `demo/_selfcheck/`（gitignore，不入库）。
2. 我自行看截图 + 读断言结果，**自行判断**是否优化并直接改。
3. 入库批次由你定；push 仍由你执行。
4. 所有"未做但值得做"的点，登记到 **§十五**，不丢。
