## 三、已知边界（如实记录，非缺陷）

1. **常规场景无区分度**：三类业务在常规场景均达 1.0，判别力仅来自 `t8_stress`（demo A6 已标注）。
2. **失配兜底不可达**：主方案下迁移目标 = 执行星 → `has_ctx` 恒真；实测命中率 1.0、切换重连额外时延 0.0（双轨同构）。叙事上称「**防御性设计**」。
3. **ns-3 单 run 浮动**：同参复跑 ~0.2–0.7%（SGP4 以墙钟为传播历元）→ 单点比对须带容差。
4. **A8 屏无数据图元**：其内容为「声明」而非「数据」，刻意保持文字形态（反对「为炫而炫」），但关键数字已走 `n()` 可溯源。
5. **`data.js` 内一处未渲染的 markdown 残留串**（`簇**发生…`）：页面使用结构化字段，不影响展示；建议下次重跑构建时清理。
6. **动画读数不属数据断言**：3D HUD 的 `T+NN s` / 仰角 / 时间游标 / 控制条 ms 为运行读数，非 `data-metric`。
