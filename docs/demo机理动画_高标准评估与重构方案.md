# demo 机理动画 · 国奖及以上标准评估与重构方案（v1）

> **用途**：为「机理/过程展示」建立**可客观打分的标尺**，据此评估当前 demo、定位差距、确定重构方案，并作为后续「优化→复评→迭代」的唯一依据。

## 四、差距结论（一句话）

> **当前把「机理」画成了「图表（泳道/格点）」；高标准要求把「机理」画成「物理过程」——有链路、有波束、有数据包在飞、有等待在转、有判决在亮，且本方案与基线同轴同时演进。**

## 五、重构方案（分屏，按机理四要素加权最高优先）

| 编号 | 屏 | 重构设计（物理化）| 关键技法 |
|---|---|---|---|
| **D-M1** | **A3 两步接入** | **「时频资源格 + 物理链路竞速」**：终端⟷卫星**物理链路 + 波束**；数据包沿链路飞行；星上处理=**转动的处理环**；四步的 RAR 窗口/竞争定时器=**转动的等待时钟 + 空转的资源格**；双面板同轴竞速，12.4 ms vs 391 ms | M1–M5、M7 |
| **D-M2** | **A4 星上认证** | **「指纹比对机」**：终端送 (假名,计数器) → 卫星持**双密钥根** → **HMAC 指纹**滑入比对（绿=吻合 / 红=不符）→ 三向判定；**假名翻牌**（每次接入 ID 可见地改变）；伪造终端**被弹回** | M1–M3、M6 |
| **D-M3** | **A5 预测切换** | **「两星信号此消彼长 + 重叠窗」**：旧星信号衰减↓、新星信号上升↑，**重叠窗**内完成 ISL 推送与 RACH-less 重连 → **链路质量曲线不掉到 0**（中断=0 直观可见）；保留 3D 与甘特 | M1–M5 |
| **D-M4** | A2 方法全景 | 流水线**实体化**：数据包「过站」时站点亮起并吐出该站指标 | M1–M3 |

## 六、实施与复评纪律

1. **逐屏重构**，每屏完成即**跑三套自检 + 负向用例**；★并做**中途取帧取证**（`ANIM.pause`+`ANIM.seek`）确认「关键量在动」而非静态截图自证。
2. 每屏复评**按评分表重新打分**，M1/M2/M4 必须达到 **≥4**，否则继续迭代。
3. 严禁为动画新增未经 `data.js` 的数据；新示意元素一律带「示意」标注。
