# demo 动画覆盖审计与参考系（第三轮·动画化）

> 触发：用户指出「技术内容仍主要在**纯文本/表格**里，而动画才应更直观」。
> 性质：这不是数据错误（前几轮已审计），而是**呈现载体错配** —— 技术点进了页面，但承载它的是文本，不是动画。
> 结论：**动画容器 7 → 13**；A6（原零动画）与 A4 的机理细节全部动画化。

---

## 一、参考系（本轮重新检索，实抓取后可迁移技法）

| 来源 | 采纳技法 |
|---|---|
| **Manim / TCP 握手动画**（animg.app / ManimCE 0.19） | **分镜法**：Intro → 各阶段 → **Timeline 总览** → Outro；**数据包带 flags 标签**；**两侧状态名随步骤点亮**（CLOSED→SYN_SENT→ESTABLISHED）；`SEQ/ACK 递增可见` |
| **协议可视化通则**（CSDN/OMNeT++/network-protocol-viz） | **数据包=小矩形/圆点 + 发光尾迹**；**分层配色**（物理/链路/网络/传输/应用各一色）；**播放/暂停/单步/重置 控件**；**每步一句说明** |
| **CPU 调度可视化器**（多实现，Vercel/GitHub） | **动画甘特图**（进程色块随时间生长 + 游标）；**就绪队列动画**；**并排对照**（FCFS vs Priority）；**实时指标随动**（等待/响应时间） |
| **3Blue1Brown / Manim 摄影术**（前轮已采纳，本轮沿用） | **视觉连续性**、**Liveness 持续运动**、**用运动表达抽象**、**镜头聚焦**、**多面板同屏** |
| **NASA Eyes / Cesium**（前轮已采纳） | 时间轴快进倒放、POI 侧栏、点击信息面板 |

**提炼的四条落地准则**：① 技术过程要有**对象在动**（包/块/游标）；② 状态与计数要**可见地推进**；③ 对比要**同轴并排**；④ 每个动画**自带播放/重播/进度条**（已有 `.abar` 控件）。

## 二、动画覆盖审计（技术点 × 是否动画）

**审计前**：`ANIM.reg` 仅 7 个（a1/a2/a3/a4/a5/a7/a8）→ **A6 与 X1 零动画**。

| 技术点 | 所在 | 审计前载体 | 判定 |
|---|---|---|---|
| 一屏总览 / 方法全景 / 两步·四步 RACH / 星上认证交互 / 预迁移切换 | A1/A2/A3/A4/A5 | 动画 | ✅ |
| 敏感性 / TRL | A7/A8 | 动画 | ✅ |
| **T8 业务分级** | A6-P2 | 图表 + 表 + 文字 | ❌ 无动画 |
| **生存优先调度** | A6-P3 | 表 + 文字 | ❌ 无动画 |
| **消融 / 资源效率 / 抗冲击** | A6-P4 | 3 张表 + 文字 | ❌ 无动画 |
| **哈希链推进** | A4 文字行 | 文字 | ❌ 无动画 |
| 证据附录 | X1 | 折叠表 | —（性质为「索引」，`run_id` 可点即够） |

**结论：4 个技术簇缺动画**（A6 全部 3 个 tab + A4 哈希链）。

## 四、技术纪律核验

| 项 | 结果 |
|---|---|
| 新增动画是否数据驱动 | ✅ 全部引 `DEMO_DATA`（`baseline_matrix` / `t8` / `priority` / `res/*` / `burst/*`） |
| 示意 vs 实测 是否标注 | ✅ `a6pri`/`a6urst` 标 `data-schematic="1"` 并在卡内含「示意」；实测数字另注「源 results/」 |
| **顺带修一处无源硬编码** | A6-P2 注原写「话音中断 0.42 ms → 552 ms」——在 `results/`/`data.js` **查无此值**（552 实为时间戳子串）→ 改为引用 `t8/话音/ns3_on/ns3_off`（0.9995 → 0.8048） |
| 几何常量集中 | ✅ 各动画的坐标常量集中在 `A6RACE`/`A6T8`/`A6PRI`/`A6RES`/`A6B`/`A4H` 对象，render 与 after 共用，避免失配 |
