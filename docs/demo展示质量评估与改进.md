### 6.2 H4 的四次自我纠错（值得记录）

结论条初稿犯了**四个**错误，均在自检/目检中抓出并修正：

1. **违反自定铁律**：初稿把 `12.06 / 381.0 / 0.8537` 等**硬编码**进字符串 —— 正是第二轮审计刚批判过的行为 → 全部改走 `n()` 或单一数据源（`D.handshake.theory`、`D.funnel`）。
2. **颜色语义错**：A1/A5 结论条里「本方案」与「对照臂」**同为青色**，违反「同一语义同一颜色」→ 对照臂改 `cls:'base'`（灰蓝）。
3. **与副标题重复**：A2/A3/A4/A6/A8/X1 结论条初稿几乎复述 `sub` → 全部重写为**带数据、不复述**的结论。
4. ★**新矛盾**：A6 结论条原写「三处提升均由**单变量**对照给出」，而同屏对撞条第 2 行标注「含**两变量**」——**自相矛盾** → 改为逐项注明口径（单变量消融臂 / 两变量切片 / 10 种子）。
