## 二、当前 demo 现状盘点（实测，非印象）

### 2.1 结构与规模

| 项 | 实测 |
|---|---|
| 屏数 | **9 屏**：`A1` 一屏看懂 → `A2` 方法全景 → `A3` 机制①两步接入 → `A4` 机制②星上认证 → `A5` 机制③预测式切换 → `A6` 结果/支撑机制（3 页签） → `A7` 可证伪 → `A8` 边界与诚实 → `X1` 证据附录 |
| 数据 | `data.js` 549,635 B：**969 项指标** / 80 个双轨对照数值 / 11936 条 trace 事件 / 25 覆盖格点 / 651 星 × 12 帧 |
| 体积 | ≈ 2.0 MB（`echarts.min.js` 1.03 MB 为唯一第三方库；3D 原生 WebGL 手写） |
| 技术栈 | 原生 JS（无框架）+ ECharts（唯一三方）+ 原生 WebGL + SVG 手绘示意 |
| 交互能力 | 切屏、对比开关（**只改呈现侧重、不改数值**）、溯源抽屉、动画播放/暂停/拖动定格、页签、折叠、ECharts `showTip` |
| 自检 | A 静态断言 / B 逐屏截图 / C 交互回归 + 负向用例；三原则 + 6 项硬检查 |

### 2.2 四维度现状（强项 / 特征）

| 维度 | 已有强项 ✅ | 当前特征 ⚠️ |
|---|---|---|
| **方法过程展示** | A2 四段流水线（数据包逐站）+ A3/A4/A5 **泳道时序梯形图** + 20×/26× 断轴放大插图；**数字与动画解耦**（数字只在「揭示」时出现，任何一帧都是真值） | 过程为**线性时间轴**；分支/决策以「并列箭头」近似；无端到端 ride-along |
| **交互机理** | 确定性动画（归一化时间 u 的纯函数）→ **可播放/暂停/拖动/定格**；可证伪（A7 参数扫描） | **「揭示型」而非「可玩型」**：读者不能改参数看机理随之变化 |
| **数据展示** | KPI 瓦片 / 对撞条 / 长表 / 敏感性折线 / 1200 事件格点；**全量 run_id 溯源 + 独立誊写副本互证** | 图形类型偏少（柱 + 2 折线）；**不确定性、分布、地理/天穹覆盖均未可视化** |
| **界面设计** | 浅色主题 + 深色侧栏、卡片体系、克制专业、信息完整 | **「工程档案」审美**：密度高、留白少、层级偏平；**颜色语义有冲突** |

### 2.3 设计系统与资产

- 配色变量：本方案 `#c0392b`（**红**）、基线 `#78909c`（灰蓝）、达标 `#1e8449`（绿）、警示 `#b7791f`、ns-3 `#2c6e9b`、Python `#7d5ba6`。
- 字体：系统字体（`Microsoft YaHei` 等），无 web font（离线约束下的正确选择）。
- 动效：屏间仅 `fade`；动画内容由 `ANIM` 引擎驱动。

## 三、差距分析（四维度对标 P1–P8）

### 3.1 方法过程展示

| # | 对标准则 | 现状 | 差距（读者会问什么） |
|---|---|---|---|
| M-1 | P1/P2 | 每屏各讲一段机制 | **缺「跟着一个终端走完全程」的端到端主线**：接入→认证→切换→业务如何首尾相接，跨屏看不出来 |

## 五、后续方案设计（分阶段路线图）

> 每阶段结束**必跑**三套自检（audit / interact / shots）+ 负向用例（必须 exit=1）；任一不过即回退本阶段。阶段内小步提交、每步可回退。

| 阶段 | 主题 | 包含项 | 目标 | 验收 |
|---|---|---|---|---|
| **Phase 0** | 分析与确认（本轮） | 本文档 | 方向确认、排期共识 | 用户确认第四/六节 |
| **Phase 1** | **稳固与统一** | D2 工程整理 + D3 颜色解耦 + D1 封面引导（轻量） | 零回归；语义统一；有开场钩子与主线引导 | 三套自检全绿；色觉抽查；文档与代码一致 |
| **Phase 2** | **机理深化** | D4 端到端 ride-along + D5 分支/状态机 + step-through | 「怎么交互」看得懂、可步进 | 交互自检新增断言；负向用例仍 FAIL |
| **Phase 3** | **数据深化** | D6 分布/CDF + 可信区间 + 覆盖天穹 + 事件流回放 | 把长尾/不确定性/空间/过程变成可看结论 | 新增图元仍走 `data.js` + `run_id`；断言数同步 |
| **Phase 4**（可选） | **对照与视觉** | D7 双轨同步 + D9 视觉升级 + D10 无障碍（**D8 可玩参数暂缓**） | 双轨对照 + 观感对齐商业级 | 数值仍可溯源；a11y 抽查 |
| **Phase 5**（可选） | 交付形态 | D11 录屏 / 规模扩展 / STK | 补齐交付形态 | 与对照表同步增行 |

**风险控制原则**：
1. **改数据零新增**：新增可视化一律从既有 `data.js` 取数；若需新指标，必须先在 `results/` 与对照表落定并重跑 `build_demo_data.py`（连带 5 类断言）。
2. **数字与动画解耦**保持：任何新动画都不得把「值」变成动画中间态。
3. **自检先行**：新交互/新图元上线前，先在 `selfcheck_interact.js`/`audit` 增加断言，再实现（断言驱动）。
4. **灰度与回退**：每项独立提交，保留旧实现开关；不通过即 `git revert` 该提交。
